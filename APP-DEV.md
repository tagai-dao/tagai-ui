# TagAI App Development

This app uses the existing Vue/Vite SPA inside a Capacitor shell. Web and app builds share the same codebase; native-only behavior must be guarded with `Capacitor.isNativePlatform()`.

## Requirements

- Node.js `>=20.19.0`
- npm
- Xcode with iOS Simulator for iOS builds
- Android Studio with Android SDK for Android builds
- Java version compatible with the generated Android Gradle project

This machine may need the local CA bundle when running npm/npx:

```sh
export SSL_CERT_FILE=/tmp/cacert.pem
export NODE_EXTRA_CA_CERTS=/tmp/cacert.pem
export npm_config_cache=/tmp/tagai-npm-cache
```

## Commands

Install dependencies:

```sh
npm install
```

Build and sync web assets into both native projects:

```sh
npm run app:sync
```

Open native projects:

```sh
npm run app:ios
npm run app:android
```

Web verification:

```sh
npm run lint
npm run type-check
npm run build-only
```

## OAuth Redirect（Privy Dashboard 配置）

Privy 的 redirect URL 与 Allowed origins 只接受 http(s)，自定义 scheme 会被 Dashboard 拒绝
（"Invalid protocol"）。原生 OAuth 链路为：

```text
系统浏览器完成 OAuth
  → https://tagai.fun/native-oauth-redirect.html   （托管跳板页，随 Web 站点部署）
  → tagai://auth-callback?<原样参数>               （跳板页深链唤起 App）
  → App 内 native.ts 严格校验 scheme/host 后转发到 /login，由 Privy SDK 消费
```

Privy Dashboard 需配置（按官方 Capacitor 配方 docs.privy.io/recipes/capacitor-oauth）：

1. **Allowed origins**（App Settings → Domains）追加两个 WebView 源：
   - `capacitor://localhost`（iOS）
   - `https://localhost`（Android）
   - 现有 https 生产域名保留；
2. **Allowed redirect URLs**（App Settings → Advanced）添加：
   - `https://tagai.fun/native-oauth-redirect.html`

注意：跳板页 `public/native-oauth-redirect.html` 必须先随 Web 站点部署到生产，
真机 OAuth 才能走通。Do not commit Privy secrets, signing keys, provisioning
profiles, keystores, or certificates.

## Deep Link Testing

iOS simulator:

```sh
xcrun simctl openurl booted "tagai://auth-callback?privy_oauth_code=test&privy_oauth_state=test"
```

Android emulator:

```sh
adb shell am start -W -a android.intent.action.VIEW -d "tagai://auth-callback?privy_oauth_code=test\\&privy_oauth_state=test" fun.tagai.app
```

Real OAuth testing must use a redirect generated by Privy. The test URLs above only verify that the app receives the scheme and routes the callback into the WebView.

## Notes

- `npm run build` and `npm run build-only` are still the Web build path. Native plugins are loaded dynamically in native-only branches.
- `npx cap sync` copies `dist` into `ios/` and `android/`; copied web assets and generated native config JSON are ignored by platform `.gitignore` files.
- Android back button maps to Vue Router history; at the root it minimizes the app.
- Embedded wallet smoke runs only on native platforms after the Privy embedded Ethereum wallet provider is available. It performs `eth_chainId` and then signs a short smoke message.
