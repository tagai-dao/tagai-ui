## 二、建议的验收路径（10 分钟走一遍）

1. **路由**：`/coins` 刷新不丢页；`/coins?tab=ip` 直达 IPShare；浏览器后退正常。
2. **四语**：右上角语言下拉切 한국어/日本語 → 看导航、Tab、时间戳（"2시간 전"）、`<html lang>`、**币卡片涨跌色翻转（中韩日红涨）**、浏览器标签页标题。
3. **币列表**：滚到底连续加载至「没有更多了」；右上「隐藏小市值」开关切换（test 币显隐）；卡片上单行描述 + 进度条/创建时间。
4. **搜索**：粘贴 `0x32ef878D527d860339818571E8DA17005110f04E` → BUIDL 卡直达。
5. **交易面板**（tag-detail）：快捷金额含 MAX；滑点 1%/3%/5% chips + 自定义、>5% 警告；输入金额后出现「最低到手」行。
6. **CA 行**：详情页 BscScan / DexScreener / GMGN 外链。
7. **预测页**：按钮内概率大字 + 上方红蓝占比条；已结束市场灰色「✓ 勝者」徽章。
8. **移动端**（窗口缩到 <804）：底栏五项带文字、未登录显示「登录」；顶栏不再有重复 + 号。
9. **中间档**（窗口 ~950px）：侧栏变 72px 图标栏、feed 居中单列。
10. **新手卡 / 空态**：首页顶部三步引导卡（✕ 关闭后不再出现）；Live Spaces 空态带「去 X 发起」链接。
